# Catálogo de Livros

Aplicação web desenvolvida em React com TypeScript e Vite para gerenciamento de um acervo de leitura. O projeto conta com um pipeline completo de CI/CD configurado via GitHub Actions, garantindo validações automáticas de linter, build e deploy automatizados.

## 🚀 Link do Projeto Publicado

Acesse o site online: https://igorlimateixeira10-cell.github.io/catalogo-livros/

## 🛠️ Tecnologias Utilizadas

* React + TypeScript
* Vite
* Tailwind CSS
* Vitest e Biblioteca de Testes (Testes)
* ESLint (Linter)
* GitHub Actions (CI/CD)

## 📋 Pré-requisitos

Certifique-se de ter o Node.js instalado em sua máquina.
